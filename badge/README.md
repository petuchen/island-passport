# Badge

```html
<a href="/island.json" title="Island Passport"><img src="https://raw.githubusercontent.com/petuchen/island-passport/main/badge/island-passport.svg" alt="Island Passport" width="168" height="28"></a>
```

Better: copy `island-passport.svg` into your own site, so your page makes no third-party request.
